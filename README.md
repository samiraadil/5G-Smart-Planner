# 5G Smart Planner

## 📡 Overview

5G Smart Planner is an intelligent web platform designed to simulate, analyze and optimize the deployment of 5G networks.

The platform helps engineers evaluate different deployment scenarios, visualize network coverage and identify optimal locations for new 5G base stations and Small Cells.

---

## 🎯 Objectives

- Simulate a virtual 5G environment.
- Visualize network coverage.
- Detect weak coverage areas.
- Optimize gNodeB deployment.
- Recommend new Small Cell locations.
- Display network KPIs.
- Provide decision support for network planning.
